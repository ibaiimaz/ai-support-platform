# Exportaciones

Un editor puede exportar las incidencias visibles desde Incidencias > Exportar CSV. Se aplican los filtros actuales. El CSV usa UTF-8 y separador punto y coma.

## Protección antes de restaurar

Para guardar cambios recientes antes de una restauración completa, filtre por fecha de actualización posterior a la copia y exporte el CSV. La exportación es una instantánea informativa y no puede importarse para restaurar automáticamente las incidencias.
